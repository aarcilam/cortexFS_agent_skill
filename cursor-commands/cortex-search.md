Busca información en CortexFS usando:

```bash
cortex search "$1"
```

Parámetros:
- $1: términos de búsqueda

Ejemplo:
```bash
cortex search "autenticación login"
```

Si hay resultados, muestra los matches y ofrece leer el contenido completo.
