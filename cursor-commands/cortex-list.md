---
description: Listar todo el conocimiento guardado en CortexFS, opcionalmente filtrado por categoría
agent: build
---

Lista el conocimiento en CortexFS:

```bash
cortex list $1
```

Sin parámetros lista todas las categorías.
Con parámetro lista entradas de esa categoría.

Ejemplos:
```bash
cortex list
cortex list agent
```
